Technical presentations as source code

Write a deck once.
Compile it everywhere.

Present2u turns a declarative P2U/1 manifest — maths, D2 diagrams, Typst, LaTeX and code — into a live presenter, a self-contained HTML file, a PDF or speaker notes. Built to be driven by agents.

One manifest, every target

# talk.p2u
p2u: 1
deck: { title: Attention Is All You Need, theme: white }
slides:
  - id: intro
    layout: section
    title: Attention
  - layout: equation
    blocks:
      - kind: equation
        source: \mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V

$ p2u validate talk.p2u
$ p2u export   talk.p2u --to html
$ p2u export   talk.p2u --to pdf

Declarative

Describe the deck; the compiler builds it. 20 layouts, 15 block kinds, diagnostics with codes and hints.

Idempotent

plan/apply diffs a manifest against a deck by stable slide id — like Terraform for slides.

Agent-friendly

A JSON Schema, a JSON API, an MCP server and an llms.txt. Agents compose, validate and publish.

Real rendering

D2 (TALA + sketch), Typst, LaTeX → SVG, KaTeX maths, Rouge code — server-rendered, cached, sanitizer-safe.

One theme

Chrome, decks and slides share one light Notion-flavoured design system.

Exports

Self-contained HTML with inlined diagrams, speaker notes, and print-ready PDF.

Open source · MIT · run it yourself

Present2u is a Rails app you clone and run — there's no account to create. Bring the toolchain and go.

# requires Ruby 3.4, d2, typst, pdflatex + pdftocairo
$ git clone https://github.com/Oreoro/present2u
$ cd present2u/writebook
$ bin/setup
$ bin/rails server -p 3010      # http://localhost:3010
$ bin/p2u doctor                # verify the toolchain
$ bin/p2u-mcp                   # MCP over stdio
