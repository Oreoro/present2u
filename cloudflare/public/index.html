One manifest, many surfaces

A deck is a document you can diff, validate and compile — not a slide editor.

Validate & compile

Parse YAML, JSON or Markdown front-matter into a versioned AST with actionable diagnostics and a slide-density budget.

Plan & apply

Stable slide ids make plan and apply idempotent — create, update, delete and reorder by diff.

Rich render targets

D2 diagrams, LaTeX maths, Typst documents and highlighted code — rendered in the browser or exported as SVG.

Agent-native

Quickstart

One manifest compiles to the same deck from every surface.

talk.p2u
# talk.p2u
p2u: 1
deck:
  title: Attention Is All You Need
  theme: violet
slides:
  - layout: section
    title: Attention
  - layout: content
    title: Why divide by sqrt(d_k)?
    body: |
      Scaling keeps the softmax in a useful range: $ \sqrt{d_k} $.
  - layout: diagram
    blocks:
      - kind: diagram
        lang: d2
        source: |
          direction: right
          a: Input -> b: Transform -> c: Output
shell
# validate, then compile with assets
bin/p2u validate talk.p2u
bin/p2u compile  talk.p2u --render --json

# export a self-contained deck or speaker notes
bin/p2u export   talk.p2u --to html
bin/p2u export   talk.p2u --to notes

# serve the compiler over MCP (stdio)
bin/p2u mcp
curl
# validate + plan (no writes)
curl -s https://p2u.focuslab.pk/api/compile \
  -H 'content-type: application/json' \
  --data-binary "$(cat talk.p2u | jq -Rs '{source: .}')"

# export a deck to PDF
curl -s https://p2u.focuslab.pk/api/export \
  -H 'content-type: application/json' \
  -d '{"source":"p2u: 1\ndeck:\n  title: Hi\nslides:\n  - layout: content\n    body: hello","to":"pdf"}' \
  -o deck.pdf
mcp
# remote MCP over Streamable HTTP
POST https://p2u.focuslab.pk/mcp
