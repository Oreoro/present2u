Quickstart

A manifest is YAML, JSON, or Markdown with front-matter.

# talk.p2u
p2u: 1
deck:
  title: Attention Is All You Need
  theme: violet
slides:
  - layout: section
    title: Attention
  - layout: content
    title: Why divide by sqrt(d_k)?
    body: |
      Scaling keeps the softmax in a useful range: $ \sqrt{d_k} $.
  - layout: diagram
    blocks:
      - kind: diagram
        lang: d2
        source: |
          direction: right
          a: Input -> b: Transform -> c: Output
# CLI
bin/p2u validate talk.p2u
bin/p2u compile  talk.p2u --render --json
bin/p2u export   talk.p2u --to html
bin/p2u mcp

API & MCP
