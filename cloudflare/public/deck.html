Why attention?

Attention lets a model weigh every token against every other token instead of squeezing a whole sentence through one fixed vector. - **Parallel** — every position is processed at once - **Content-based** — weights come from similarity, not position - **Differentiable** — trained end to end with gradient descent The core operation: $ \operatorname{Attention}(Q,K,V) = \operatorname{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V $
2 / 10

Scaled dot-product attention

Each query is compared with every key. The scores are scaled, normalised with a softmax, then used to blend the values. @@P2U_ASSET_0@@ Scaling by $\sqrt{d_k}$ keeps the logits in a range where softmax still has a useful gradient.

Multi-head attention

One attention head can only express one notion of "relevance". Multi-head attention runs several in parallel and concatenates the result. - Each head learns a different projection of $Q$, $K$ and $V$ - Heads specialise — syntax, coreference, position - Outputs are concatenated and mixed by $W^O$
5 / 10

In code

```python import torch def attention(q, k, v, mask=None): scores = q @ k.transpose(-2, -1) / q.size(-1) ** 0.5 if mask is not None: scores = scores.masked_fill(mask == 0, float("-inf")) weights = scores.softmax(dim=-1) return weights @ v ```

Inside a block

A Transformer block stacks two residual sub-layers: 1. **Multi-head self-attention** — tokens exchange information 2. **Feed-forward network** — each token is transformed independently Layer norm, residuals and dropout keep the stack trainable at depth.
